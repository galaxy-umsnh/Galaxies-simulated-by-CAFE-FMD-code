Este repositorio tiene como propósito alojar las imágenes generadas con el proyecto "Formación de galaxias tipo medusa según el modelo de materia oscura bosónica (MOBU)" entre mayo del 2024 y enero del 2025. 
De aproximadamente 80 simulaciones exitosas, se obtuvieron 20 imágenes para cada una desde distintos ángulos de perspectiva, con el objetivo de compararlas con imágenes clasificadas como 'galaxias medusa' 
a través de un modelo de redes neuronales y, de esta manera, poder apoyar o demeritar el modelo MOBU.
